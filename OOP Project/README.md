# Exam System

A C# OOP-based Exam System designed to demonstrate core Object-Oriented Programming concepts such as:

- Abstraction
- Inheritance
- Polymorphism
- Encapsulation
- Interfaces (`ICloneable`, `IComparable`)
- Object Relationships
